# Getting help

how2vote is a non-partisan public-interest tool operated by National Digital. Here is how to get
help, depending on what you need.

## Questions and general contact

Use the [contact page](https://how2vote.au/contact) for general questions, media enquiries, or
anything that is not a code bug. The contact channel is monitored during a campaign.

## Reporting a data error or correction

Wrong candidate, party mapping, ballot order, or alignment figure? Corrections have their own
process — please follow [`docs/corrections.md`](docs/corrections.md), or open a
**Data correction** issue using the template. Corrections are logged publicly and, during an
election period, prioritised.

## Bugs and feature requests

Open an issue using the bug-report or feature-request templates in the repository. Please search
existing issues first.

## Security issues

Do **not** open a public issue for anything exploitable. Report security vulnerabilities privately
as described in [`SECURITY.md`](SECURITY.md).
